# QA Engineer

Role: Ensures product quality through testing strategy, automation, and verification of features across CloudCreator AI OS.

Responsibilities:
- Develop and maintain test plans, test cases, and automated test suites.
- Coordinate regression testing and continuous integration checks.
- Validate functional, performance, and security requirements.
- Triage issues and work with engineers to reproduce and resolve defects.

Skills & Tools:
- Test automation frameworks (Selenium, Playwright, Jest, pytest).
- CI/CD integration, test ownership, and QA metrics tracking.
- Familiarity with performance and security testing tools.
