# Architecture Designer

Role: Designs system and software architecture, ensuring modularity, scalability, and maintainability across CloudCreator AI OS.

Responsibilities:
- Create high-level architecture diagrams and component specifications.
- Define interfaces, integration patterns, and API contracts.
- Ensure alignment between product goals and technical implementation.
- Review technical proposals and mentor engineering teams on architectural decisions.

Skills & Tools:
- Systems design, domain-driven design, and API design experience.
- Familiarity with UML/architecture diagramming tools and documentation best practices.
- Knowledge of trade-offs in performance, scalability, and cost.
